## 👋 Sobre mim

Sou **Wesley Lauwer**, tenho 26 anos e curso **Análise e Desenvolvimento de Sistemas no IFES**.

Sou policial militar e estou construindo um novo caminho na tecnologia. Depois de um primeiro contato com programação, decidi retomar os estudos e transformar esse interesse em carreira. Da farda eu trago **disciplina, atenção aos detalhes e responsabilidade com o que entrego**.

Hoje concentro meus esforços em fortalecer a base de **HTML, CSS, lógica de programação e JavaScript**, com o objetivo de evoluir para o desenvolvimento **Full Stack** e criar soluções que atendam a necessidades reais.

Este GitHub é o registro público dessa evolução: projetos, experimentos e aprendizados.
